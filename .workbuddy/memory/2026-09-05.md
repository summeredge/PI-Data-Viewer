## 复盘：箱线图箱宽仍随位号变化（21:10 反馈）

- 用户复测反馈：随位号增加，箱体本身宽度仍在变。复盘根因：之前只固定了外框 width，但 `make_subplots` 默认按「1 个 subplot = 1 列」，每个箱子的宽度还吃掉了 y 轴 tick 文字宽度，所以位号越多，y 轴越窄，每个箱子就相对越宽。
- 修订方案（每个箱子物理宽度不变）：
  - `charts/boxplot.py`：导入 `MAX_TAGS`，固定 `_BOX_COLUMNS = MAX_TAGS`；`make_subplots(rows=1, cols=_BOX_COLUMNS, column_widths=[1/_BOX_COLUMNS]*_BOX_COLUMNS)`，把真实箱体放在前 n 列、`visible=False` 隐藏后 8-n 列的 x/y 轴 → 每个 subplot 列宽恒为 1/8 页宽；活动 x/y 轴显式 `visible=True`（避免 Plotly 默认 None 让断言/状态查询拿到 None）。
  - `pages/viewer.py`：`_boxplot_frame_style` 简化为：空图 100%，非空图一律 100%（每个子图列已经按 1/8 切好，外框不再缩放）。
  - `tests/test_boxplot.py`：原 `test_boxplot_frame_width_keeps_each_column_at_one_eighth` 改为断言 1/2/8 位号 frame style 都是 `{"width":"100%"}`；新增 `test_boxplot_figure_always_has_eight_subplot_columns`：断言 8 个 xaxis key（`xaxis`/`xaxis2`..`xaxis8`）、`xaxis.visible is True`、`xaxis2..xaxis8.visible is False`、margin.b==110；并修正 xaxis key 过滤器要包含裸 `"xaxis"`（`key == "xaxis" or key[5:].isdigit()`）。
- 测试：100 passed（含 2 个箱线图相关断言）。
- 服务：app 重启后 `/_dash-layout` 含 `boxplot-visualization-frame` 且 styles.css 加载 200。
